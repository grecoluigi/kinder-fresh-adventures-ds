First public release of the Nintendo DS port of Kinder Fresh Adventures.

Includes the four worlds, tutorials, enemies and bosses, character switching, bottom-screen HUD and touch menus, music/voices, credits, highscores and DS keyboard name entry.

Build from the supported original Italian Collection ISO using the included extraction and conversion tools. See the README for the exact disc hashes and build instructions.

The Jungle tutorial and first level have been tested on a physical DS. Complete playthroughs, remaining worlds and flashcart save durability still need verification. Report the world, location, DS model and loader when filing an issue.
