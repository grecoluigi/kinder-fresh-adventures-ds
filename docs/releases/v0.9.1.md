Graphics update for the Nintendo DS port of Kinder Fresh Adventures.

All artwork that is shrunk to fit the DS screens is now resampled with a smoother filter (Lanczos) instead of picking single pixels. Outlines on the HUD, characters, enemies, pickups and level scenery no longer look jagged or broken, and shading has fewer stray pixels. Score digits and fonts are unchanged.

Performance, memory use and ROM size are essentially the same as 0.9.0. Saves from 0.9.0 keep working.

This release also fixes the build-from-source instructions, which stopped at the asset assembly step in 0.9.0.

Download **Kinder Fresh Adventures.nds** from the assets below and copy it to your DS flashcart, or open it in a DS emulator. The accompanying `.sha256` file verifies the download.

The Jungle tutorial and first level have been tested on a physical DS. Complete playthroughs, remaining worlds and flashcart save durability still need verification. Report the world, location, DS model and loader when filing an issue.
